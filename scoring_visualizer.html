Understanding the Code Math

Engine A: Modern Speed Decay

// 1. Resolve base difficulty score const base = { easy: 600, medium: 800, hard: 1000 }[difficulty]; // 2. Clamp response times below 500ms const response = Math.max(500, timeLimit - remaining); const effRemaining = Math.max(0, timeLimit - response); // 3. Calculate points multiplier (0.5 to 1.0) const factor = 0.5 + 0.5 * (effRemaining / timeLimit); const timeScore = Math.round(base * factor); // 4. Streak bonus: starts at 2nd correct (+100/ea), capped at +500 const streakBonus = Math.min(Math.max(streak - 1, 0) * 100, 500); const total = timeScore + streakBonus;

Engine B: Legacy Challenge Formula

// 1. Retrieve raw score value configured in DB let points = scorePoints; // 2. Time-spent bonus: up to +50% of base points if (isChallenge && timeSpent < timeLimit) { const ratio = 1 - timeSpent / timeLimit; const bonus = Math.floor(scorePoints * ratio * 0.5); points += bonus; } const total = points;
