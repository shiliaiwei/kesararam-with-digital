## Neo-Brutalist Styling Guidelines

- **Borders**: `border-2 .... ` on all elements
- **Shadows**: `shadow-[4px_4px_0_#000]` hard shadows only
- **No border-radius** — sharp corners mandatory
- **Color palette**:
  - Yellow: `#eab308`
  - Blue: `#3b82f6`
  - Red: `#ef4444`
  - Green: `#22c55e`
  - Orange: `#f97316`
  - Cyan: `#06b6d4`
  - Purple: `#a855f7`
  - Rose: `#fda4af`
  - Gray: `#a8a8a8`
  - Dark Green: `#006747`
  - White: `#ffffff`
    #a8a8a8 #006747 #ffffff
- **No gradients** — solid colors only
- **No emoji** in UI text
