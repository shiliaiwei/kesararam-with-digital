# Quiz Game - Quick Start Guide

## For Students

### Join Live Game
1. Go to `/play`
2. Enter 6-character game code
3. Wait in lobby for teacher to start
4. Answer questions before timer runs out
5. See your rank on leaderboard after each question

### Solo Practice
1. Go to `/play`
2. Click "Solo Practice"
3. Choose mode (Quick Quiz, Speed Round, etc.)
4. Select category and difficulty
5. Answer questions to build your streak
6. Track your personal best scores

## For Teachers

### Host Live Game
1. Go to `/teacher/sessions`
2. Click "Host New Game"
3. Select game mode, category, difficulty
4. Share 6-character code with students
5. Wait for students to join lobby
6. Click "Start Game" to begin
7. Use controls:
   - "Next Question" - advance to next question
   - "Show Leaderboard" - display current rankings
   - "Pause/Resume" - control game flow
   - "End Game" - finish and show podium

### View Analytics
1. After game ends, click "View Analytics"
2. See detailed stats:
   - Question-by-question breakdown
   - Student performance metrics
   - Answer distribution
3. Export data as CSV

## For Admins

### Manage All Sessions
1. Go to `/admin/game-sessions`
2. View all active and past games
3. Terminate problematic sessions
4. Monitor system usage

## Game Modes

- **Quick Quiz** (10Q/30s) - Fast general knowledge
- **Speed Round** (20Q/15s) - Rapid-fire questions
- **Sign Challenge** (15Q/20s) - Traffic signs only
- **Mixed Battle** (20Q/30s) - All question types
- **Daily Challenge** (15Q/30s) - Daily special
- **Exam Simulation** (40Q/45s) - Full exam practice

## Scoring System

- **Base Points**: 1000 per correct answer
- **Speed Bonus**: Faster answers = more points (speed mode)
- **Streak Bonus**: Up to 50% extra for consecutive correct answers
- **Max Streak**: 5x multiplier

## Tips

- Answer quickly in speed mode for maximum points
- Build streaks for bonus multipliers
- Practice solo to improve before live games
- Teachers can pause games if needed
- All scoring is server-side (no cheating possible)
