## 2024-05-18 - Avoid re-computing array filter & reduce operations on generic UI state changes\n**Learning:** The catalog components (`DrivingCatalogue` and `RoadTrafficCatalogue`) used to re-calculate heavy lists (e.g. `topics.filter()` and `topics.reduce()`) on *every render*, even when only local UI state (such as `expandedTopic` for expanding an accordion item) changed.\n**Action:** Use `useMemo` to cache these derived state operations so they only re-run when their actual dependencies (`topics`, `search`, or `subGroupFilter`) change.
