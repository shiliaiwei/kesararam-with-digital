```bash
# Set your GitHub email

# Verify the changes

```

## Auto-Push Rules Configured

### 1. **Auto-push after task completion**
- **Trigger**: When a spec task is marked as completed
- **Action**: Automatically pushes to `origin/docs`
- **Hook ID**: `auto-push-after-fix`

### 2. **Auto-commit and push on agent stop**
- **Trigger**: When the agent finishes working
- **Action**: Commits all changes with message "chore: Auto-commit changes" and pushes
- **Hook ID**: `auto-commit-push-on-stop`

### 3. **Auto-push on file save**
- **Trigger**: When TypeScript/TSX files are saved in `src/` directory
- **Action**: Commits changes and pushes to `origin/docs`
- **Hook ID**: `auto-push-on-file-save`
- **File patterns**: `src/**/*.tsx`, `src/**/*.ts`

## Workflow

After each fix or feature:
1. Make your changes
2. Save the files
3. The hooks will automatically:
   - Commit the changes
   - Push to GitHub
   - Display a summary

## To Change Repository

If you want to push to your own private repository instead:

```bash
# Change the remote URL
git remote set-url origin https://github.com/YOUR_USERNAME/YOUR_REPO.git

# Verify
git remote -v
```
