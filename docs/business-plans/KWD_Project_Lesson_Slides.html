The Problem

Why this matters

Road risk is high

Cambodia has one of the region's highest road-crash rates. Many crashes trace back to weak knowledge of signs and rules.

Study material is scarce

Official theory content is limited, often paper-only, and rarely available in clear, modern Khmer-first digital form.

Learning is not engaging

Rote memorization is boring. Students need interactive practice, feedback, and motivation to keep going.

Our question: How can we make correct road-safety knowledge free, fun, and accessible to every Cambodian student — in their own language?

Our Solution

What is KWD?

KWD is a free, bilingual (Khmer + English) web platform that turns road-safety theory into an interactive learning experience.

Learn

Structured lessons across 8 knowledge areas with signs, images, and references.

Play

Solo quizzes and category practice with instant feedback.

Compete

Live classroom games hosted by teachers, with a leaderboard.

Ask AI

"Suar AI" answers road-rule questions in Khmer or English.

Who it is for

Students, teachers, and new drivers preparing for the license theory test.

Languages

Full Khmer + English everywhere; switch with one tap.

Cost

Free for students. Teachers can upgrade for advanced class tools.

How It Works · Live Classroom Game

Real-time multiplayer quiz

Teacher side

  • Creates a session and picks categories & difficulty
  • A unique game code + QR code is generated
  • Teacher presents questions on a big screen
  • Controls the pace; correct answers reveal automatically

Student side

  • Scans the QR code or enters the game code
  • Joins the lobby on their phone (full-screen)
  • Answers each question against a timer
  • Sees instant feedback and live ranking

The technology behind it: Pusher (websockets) sends questions and scores to every device at the same moment, so the whole class stays in sync in real time.

Feature · Suar AI

An AI study assistant

What it does

  • Answers questions about signs, rules, and driving
  • Explains in Khmer or English
  • Helps students who are stuck while studying

How it works

  • A large language model (LLM) processes the question
  • The app sends the prompt securely from the server
  • The answer is streamed back to the student

System Architecture

How the pieces connect

Browser

Student / teacher device. Renders pages, runs the live game UI.

→

Next.js Server

Server actions + API routes handle all logic and writes.

→

PostgreSQL

Stores users, content, questions, scores — 36 tables.

Pusher

Pushes live questions & scores to every player at once.

Cloudinary

Serves sign images and audio quickly.

AI + Mapbox

External services for the assistant and live traffic map.

Security: All database writes go through the server. Secret keys (database, AI, payments) never reach the browser. Backend dashboards are hidden from the public.

Design Identity

Road safety, made into a UI

Brutalist + traffic-sign style

  • Sharp corners, solid black borders
  • Hard offset shadows, no blur, no gradients
  • Caution-tape accents (yellow + black)
  • Library icons only — no emoji

Color used like a road sign

Yellow · CTA / warning Red · stop / danger Green · go / correct Blue · info Orange · caution Purple · premium

Every color carries a meaning, just like real road signage.
