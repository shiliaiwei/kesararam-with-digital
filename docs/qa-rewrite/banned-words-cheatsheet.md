# Q&A ពាក្យហាមឃាត់ — Cheatsheet
> មើលបញ្ជីនេះរាល់ពេលបង្កើត Q&A។ បើឃើញពាក្យហាមឃាត់ → សរសេរឡើងវិញ។

## ពាក្យដែលអ្នកហាមឃាត់ → ប្រើជំនួស
| ❌ ហាមឃាត់ | ✅ ប្រើជំនួស |
|------------|-------------|
| ត្រូវ ឬ មិនត្រឹមត្រូវ | ត្រូវ ឬ ខុស |
| ដ៏ · ជានិច្ច | រាល់ពេល / គ្រប់ពេល |
| សេចក្តីថ្លែងការណ៍មួយណា · ថ្លែងការណ៍ | សួរផ្ទាល់ / ឃ្លាណាមួយ |
| ប៉ប៉ោរ | និយាយធម្មតា |

## ពាក្យបន្ថែម (ផ្លូវការ → ធម្មតា)
| ❌ ហាមឃាត់ | ✅ ប្រើជំនួស |
|------------|-------------|
| នូវ | លុបចេញ |
| នៃ | របស់ |
| ឡើយ | ទេ |
| ពុំ | មិន / អត់ |
| ត្រូវបាន | active voice |
| ទាំងឡាយ | ទាំងអស់ |
| នានា | ផ្សេងៗ |
| ជាអាទិ៍ | ជាដើម |
| ប្រការ | រឿង |
| អនុលោម | ធ្វើតាម / គោរព |
| បទប្បញ្ញត្តិ | ច្បាប់ / វិន័យ |
| នីតិវិធី | ជំហាន / របៀប |
| ប្រតិបត្តិ | ធ្វើតាម |
| ដ៏សែន | ខ្លាំង |

## និមិត្តសញ្ញា / ទឹកដម
- គ្មាន emoji
- គ្មាន `&` → សរសេរ `និង`
- គ្មាន `*`
- គ្មានសញ្ញា `៖`
- មិនប្រើពាក្យផ្លូវការ / ច្បាប់
- សួរឲ្យខ្លី — មួយប្រយោគ មួយគំនិត
- Khmer ធម្មតាដែលសិស្សនិយាយ — មិនបកប្រែពាក្យពីអង់គ្លេស
- True/False = សរសេរជា scenario ខ្លី — មិនដាក់ "ត្រូវ ឬ ខុស" នៅខាងដើម
- Sign Challenge = សំណួរជាអក្សរ (មិនបង្ហាញរូបនៅលើ) → ជម្រើសជារូបសញ្ញា ៤ (ត្រឹមត្រូវ ១ + ខុស ៣)
